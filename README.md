## 🚀 Featured Project

### 🍽 Tippecanoe Restaurant Inspection Analytics Platform

**Full-Stack Data Science | Data Engineering | Machine Learning**

Built an end-to-end analytics platform processing 2,500+ restaurant inspection records from Tippecanoe County.

#### Key Features

- Automated ETL pipelines for data collection and cleaning
- PostgreSQL database with normalized schema design
- FastAPI REST API serving inspection and violation data
- Restaurant risk-scoring engine
- Machine learning models predicting inspection failures
- Interactive analytics dashboards and geographic hotspot analysis
- Dockerized architecture for deployment

#### Technologies

`Python` `FastAPI` `PostgreSQL` `SQLAlchemy` `React` `Next.js`
`Docker` `Scikit-Learn` `XGBoost` `Power BI`
